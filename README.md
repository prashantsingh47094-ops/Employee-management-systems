# 💼 Employee Payroll Management System

## 📌 About The Project

The **Employee Payroll Management System** is a simple project developed using C++. I created this project to make employee record management and salary calculation easier.

It allows users to manage employee information, calculate salaries automatically, and generate detailed payslips. The system uses C++ programming concepts and file handling to manage employee records.

## ✨ Key Features

| Feature | Description |
|---|---|
| ➕ Add Employee | Add new employee details |
| 👥 View Employees | Display all employee records |
| 🧾 Generate Payslip | Generate detailed salary slips |
| ✏️ Update Employee | Modify existing employee details |
| 🗑️ Delete Employee | Remove employee records |
| 💾 File Storage | Store employee data permanently |
| 🧮 Salary Calculation | Calculate salary automatically |

## 🛠️ Technologies Used

- **C++** – Main programming language.
- **OOP Concepts** – To organize employee data and operations.
- **File Handling** – To store and manage employee records.
- **STL Libraries** – To manage data and perform operations.
- **VS Code / Code::Blocks** – For writing and running code.

## 💰 Salary Calculation

The system calculates salary using the following components:

| Salary Component | Percentage |
|---|---:|
| HRA | 20% |
| DA | 10% |
| PF | 12% |
| Income Tax | 5% |

**Net Salary = Gross Salary - Total Deductions**

## 🚀 How to Run

**Step 1:** Install a C++ compiler such as GCC or MinGW.

**Step 2:** Save the source code as `payroll.cpp`.

**Step 3:** Open the terminal in the project folder.

**Step 4:** Compile the program using:

```bash
g++ payroll.cpp -o payroll
```

**Step 5:** Run the program:

```bash
./payroll
```

For Windows:

```bash
payroll.exe
```
